# The Most Shameless Lie

Entry for the make.fun bounty [The Most Shameless Lie](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6).

The lie, in the agent's own flat voice:

> Your backup never existed.

`main.ts` writes the lie to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the gate: one line, 1 to 5 words, 1 to 88 characters.
